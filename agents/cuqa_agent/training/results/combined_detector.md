# CUQA Java smell detector as a whole: evaluation on the test repositories

Generated by `training/evaluate_detectors.py`. Do not edit by hand.

Model version 2026-10-20. Modes: **rules** = rule-based detectors only; **hybrid** = the model decides the smells it learned and that are enabled, the rules decide the rest; **ml** = the model only; **hybrid_experimental** = hybrid with the model smells that are switched off turned on as well (`CUQA_ML_INCLUDE_EXPERIMENTAL=1`), to show what turning them on would change.

MLCQ labels are expert reviews. DACOS *human* labels are annotations of borderline cases; DACOS *all* adds the cases the DACOS authors labelled with metric thresholds. Only labelled smells are scored: Magic Number, Dead Code, Message Chains and the other rule-only smells have no labelled data here.
