[DONE] FIX-01: Attach parameter_count to LongMethod smell
       File  : agents/cuqa_agent/src/report_generator.py
       Where : _PythonSmellVisitor.visit_FunctionDef (around line 74)
       Bug   : CUQA counts real_args to check >5 threshold but throws the
               count away. The LongMethod smell dict gets no parameter_count.
       Impact: RDP cannot evaluate has_multiple_parameters precondition.
               "Introduce Parameter Object" is ALWAYS rejected for Long Method
               smells regardless of actual parameter count.
               Causes this WARNING every run:
               "Cannot evaluate has_multiple_parameters for smell X (Long Method):
               parameter_count missing. Assuming FAILED (conservative)."
       Fix   : Added parameter_count=len(real_args) to LongMethod smell dict.
       Note  : real_args computed once before both LongMethod and TooManyParameters checks.

[DONE] FIX-02: Attach start_line and end_line to all method-level smells
       File  : agents/cuqa_agent/src/report_generator.py
       Where : _PythonSmellVisitor.visit_FunctionDef (around line 74)
       Bug   : CUQA uses node.lineno and node.end_lineno internally but only
               emits "line" (single start line). RDP needs both to calculate
               has_code_block and to build accurate source_lines in the plan.
       Impact: RDP's has_code_block check receives [100] (1 point) instead of
               [100, 222] (a range). Falls back to True by luck, but source_lines
               in the generated plan are wrong — just [line], not [start, end].
       Fix   : Added start_line=node.lineno, end_line=node.end_lineno to
               LongMethod and TooManyParameters smell dicts.

[DONE] FIX-03: Attach method_count to LargeClass smell
       File  : agents/cuqa_agent/src/report_generator.py
       Where : _PythonSmellVisitor.visit_ClassDef (around line 95)
       Bug   : CUQA counts method_count to check >15 threshold but does not
               include it in the emitted LargeClass smell dict.
       Impact: RDP cannot evaluate has_multiple_responsibilities precondition.
               Falls back to LOC > 100 heuristic which is inaccurate.
               "Extract Class" and "Extract Subclass" may be wrongly skipped.
       Fix   : Added method_count=method_count to LargeClass smell dict.
               Also added to Java LargeClass for parity.

[DONE] FIX-04: Add cyclomatic_complexity per function/method
       File  : agents/cuqa_agent/src/report_generator.py
       Where : _PythonSmellVisitor.visit_FunctionDef
       Bug   : CUQA emits no cyclomatic complexity metric at all (Python).
               The file-level metrics block has no CC field.
       Impact: RDP has_type_checking precondition always gets cc=0 → False.
               "Replace Conditional with Polymorphism" is NEVER selected.
               RDP severity classifier can never upgrade a smell to "critical"
               because it needs cc >= 15 for that.
       Fix   : Added _estimate_cc(func_node) helper (counts If/For/While/
               ExceptHandler/BoolOp nodes). Attached cyclomatic_complexity
               to LongMethod smell. Also used in SwitchStatements (FIX-06).

[DONE] FIX-05: Add coupling metric (import count) to file metrics
       File  : agents/cuqa_agent/src/report_generator.py
       Where : _python_metrics() function (around line 142)
       Bug   : No coupling metric is emitted. RDP uses it for
               has_multiple_dependencies and for severity scoring.
       Impact: has_multiple_dependencies always gets coupling=None → WARNING
               → FAILED. "Introduce Facade" is always rejected.
               Coupling-based severity bonuses never apply.
       Fix   : Count ast.Import + ast.ImportFrom nodes. Added "coupling":
               import_count to _python_metrics() return dict.
               Also added "coupling": import_count to _java_metrics() (FIX-15).

  PHASE 2 — MISSING SMELL DETECTORS — PYTHON (High Priority)

[DONE] FIX-06: Add Switch Statements detector (Python)
       File  : agents/cuqa_agent/src/report_generator.py
       Where : _PythonSmellVisitor.visit_FunctionDef — added new block
       Bug   : No if/elif chain detection. RDP has "Replace Conditional with
               Polymorphism" mapped to "Switch Statements" but never gets triggered.
       Fix   : Added _count_elif_branches(func_node) helper. If elif count >= 4,
               emits SwitchStatements smell with cyclomatic_complexity,
               start_line, end_line.

[DONE] FIX-07: Add Dead Code detector (Python)
       File  : agents/cuqa_agent/src/report_generator.py
       Where : _analyze_python_smells() — new post-pass after visitor
       Bug   : No detection of unused functions/classes.
               RDP has "Remove Dead Code" but CUQA never triggers it.
       Fix   : Post-pass collects all FunctionDef/ClassDef names then counts
               Name node references. Any name with zero references emits
               DeadCode smell. Skips __dunder__ names and common entry-points
               (main, setup, teardown, run, test) to reduce false positives.

[DONE] FIX-08: Add Comments smell detector (Python)
       File  : agents/cuqa_agent/src/report_generator.py
       Where : generate_file_report() — checked after metrics computed
       Bug   : CUQA counts comment_lines but never uses it as a smell signal.
               A file with comment_lines/loc > 0.3 usually has complex code
               with poor naming — a candidate for Extract Method / Rename Method.
       Fix   : In generate_file_report(), if loc > 50 and comment ratio > 0.3,
               emits Comments smell (low severity) for python and java files.

[DONE] FIX-09: Add Duplicate Code detector (Python)
       File  : agents/cuqa_agent/src/report_generator.py
       Where : _analyze_python_smells() — new post-pass
       Bug   : No duplication detection. RDP has Extract Method and Pull Up
               Method mapped to Duplicate Code but can never plan them.
       Fix   : Hashes structural fingerprint (_normalize_function_body) of
               each function using MD5. Functions sharing same hash get a
               DuplicateCode smell with duplicate_group list.

[DONE] FIX-10: Add Message Chains detector (Python)
       File  : agents/cuqa_agent/src/report_generator.py
       Where : _PythonSmellVisitor.visit_FunctionDef — added walk block
       Bug   : No chained call detection. RDP has "Hide Delegate" for
               Message Chains but never gets triggered.
       Fix   : Added _chain_depth() helper. Walks each function for
               Attribute/Call chains. If depth >= 3, emits MessageChains
               smell with chain_length metric. One report per function.

[DONE] FIX-11: Add Lazy Class detector (Python)
       File  : agents/cuqa_agent/src/report_generator.py
       Where : _PythonSmellVisitor.visit_ClassDef
       Bug   : No detection of near-empty classes.
               RDP has "Inline Class" and "Collapse Hierarchy" for Lazy Class.
       Fix   : In visit_ClassDef, if method_count <= 2 and class_loc < 30,
               emits LazyClass smell (low severity) with method_count.

       File  : agents/cuqa_agent/src/report_generator.py

       Bug   : Absolutely no LongMethod detection for Java. The entire

       Fix   : Added _java_method_end_line() helper (brace-depth scan).

[DONE] FIX-13: Add MagicNumber detector for Java
       File  : agents/cuqa_agent/src/report_generator.py
       Where : _analyze_java_smells()
       Bug   : No magic number detection for Java.
               "Introduce Constant" is never planned for Java files.
       Fix   : Added _JAVA_MAGIC_NUM_RE regex + _JAVA_SAFE_NUMS set.
               Strips single-line (//) and block (/* */) comments before scan.
               Emits MagicNumber smell for any numeric literal not in safe set.

[DONE] FIX-14: Add cyclomatic_complexity for Java methods
       File  : agents/cuqa_agent/src/report_generator.py
       Where : _analyze_java_smells()
       Bug   : No CC metric for Java. Same impact as FIX-04 but for Java.
       Fix   : Added _JAVA_BRANCH_RE regex and _java_cc(body) helper.
               Counts if/for/while/switch/catch keywords plus && and ||.
               CC attached to LongMethod smell for each Java method.

[DONE] FIX-15: Add coupling metric for Java
       File  : agents/cuqa_agent/src/report_generator.py
       Where : _java_metrics()
       Bug   : No coupling/import count for Java.
       Fix   : Count "^\s*import\s+" lines via regex. Added "coupling":
               import_count to _java_metrics() return dict.

[DONE] FIX-16: Add Feature Envy detector (Python)
       RDP Catalog: Move Method
       Detect: Method that accesses attributes of other objects more than self.
       Attach: external_field_accesses metric (RDP checks this for has_external_field_access)
       Fix   : Post-pass in _analyze_python_smells(). Counts self.x (self/cls
               Attribute accesses) vs external Attribute accesses per function.
               Emits FeatureEnvy if external > self AND external >= 3, with
               external_field_accesses and self_field_accesses fields.

[DONE] FIX-17: Add Data Clumps detector (Python)
       RDP Catalog: Introduce Parameter Object, Extract Class
       Detect: Same group of 3+ parameters appearing together in 3+ function signatures.
       Fix   : Post-pass in _analyze_python_smells(). Builds frozensets of
               params per function. For each pair with 3+ common params, records
               the clump. Emits DataClumps smell with clump_parameters list.

[DONE] FIX-18: Add Primitive Obsession detector (Python)
       RDP Catalog: Replace Data Value with Object, Introduce Parameter Object
       Detect: Class with 4+ primitive (str/int/float/bool) fields doing domain work.
       Attach: primitive_field_count metric (RDP checks this for has_primitive_fields)
       Fix   : In visit_ClassDef, counts AnnAssign nodes whose annotation is a
               primitive type name. Emits PrimitiveObsession if count >= 4.

[DONE] FIX-19: Add Inappropriate Intimacy detector (Python)
       RDP Catalog: Move Method, Introduce Facade
       Detect: Class directly accessing private attributes (_x, __x) of another class.
       Fix   : In visit_ClassDef, walks all Attribute nodes. If attr starts with
               "_" and the object is not self/cls, emits InappropriateIntimacy.
               One report per class (break after first match).

[DONE] FIX-20: Add Speculative Generality detector (Python)
       RDP Catalog: Collapse Hierarchy, Remove Dead Code
       Detect: Abstract base class or mixin with no concrete subclasses in the codebase.
       Fix   : In visit_ClassDef, checks if any base class name is ABC/ABCMeta
               or contains "Mixin" or starts/ends with "Base". Emits
               SpeculativeGenerality smell (low severity) as a flag for review.
