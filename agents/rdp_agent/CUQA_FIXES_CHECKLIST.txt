  PHASE 1 — MISSING FIELDS ON EXISTING SMELLS (Critical)
  These fixes stop the WARNING logs in RDP agent and unlock blocked candidates.

[ ] FIX-01: Attach parameter_count to LongMethod smell
       File  : agents/cuqa_agent/src/report_generator.py
       Where : _PythonSmellVisitor.visit_FunctionDef (around line 74)
       Bug   : CUQA counts real_args to check >5 threshold but throws the
               count away. The LongMethod smell dict gets no parameter_count.
       Impact: RDP cannot evaluate has_multiple_parameters precondition.
               "Introduce Parameter Object" is ALWAYS rejected for Long Method
               smells regardless of actual parameter count.
               Causes this WARNING every run:
               "Cannot evaluate has_multiple_parameters for smell X (Long Method):
               parameter_count missing. Assuming FAILED (conservative)."
       Fix   : Add parameter_count to the smell dict when emitting LongMethod:
                   extra={"parameter_count": len(real_args)}

[ ] FIX-02: Attach start_line and end_line to all method-level smells
       File  : agents/cuqa_agent/src/report_generator.py
       Where : _PythonSmellVisitor.visit_FunctionDef (around line 74)
       Bug   : CUQA uses node.lineno and node.end_lineno internally but only
               emits "line" (single start line). RDP needs both to calculate
               has_code_block and to build accurate source_lines in the plan.
       Impact: RDP's has_code_block check receives [100] (1 point) instead of
               [100, 222] (a range). Falls back to True by luck, but source_lines
               in the generated plan are wrong — just [line], not [start, end].
       Fix   : Add to every method smell:
                   "start_line": node.lineno,
                   "end_line": node.end_lineno or node.lineno

[ ] FIX-03: Attach method_count to LargeClass smell
       File  : agents/cuqa_agent/src/report_generator.py
       Where : _PythonSmellVisitor.visit_ClassDef (around line 95)
       Bug   : CUQA counts method_count to check >15 threshold but does not
               include it in the emitted LargeClass smell dict.
       Impact: RDP cannot evaluate has_multiple_responsibilities precondition.
               Falls back to LOC > 100 heuristic which is inaccurate.
               "Extract Class" and "Extract Subclass" may be wrongly skipped.
       Fix   : Add to the LargeClass smell dict:
                   extra={"method_count": method_count}

[ ] FIX-04: Add cyclomatic_complexity per function/method
       File  : agents/cuqa_agent/src/report_generator.py
       Where : _PythonSmellVisitor.visit_FunctionDef
       Bug   : CUQA emits no cyclomatic complexity metric at all (Python).
               The file-level metrics block has no CC field.
       Impact: RDP has_type_checking precondition always gets cc=0 → False.
               "Replace Conditional with Polymorphism" is NEVER selected.
               RDP severity classifier can never upgrade a smell to "critical"
               because it needs cc >= 15 for that.
       Fix   : Count branch nodes inside each function and attach CC to smell:
                   def _estimate_cc(func_node):
                       cc = 1
                       for n in ast.walk(func_node):
                           if isinstance(n, (ast.If, ast.For, ast.While,
                                             ast.ExceptHandler, ast.BoolOp)):
                               cc += 1
                       return cc
               Then add: extra={"cyclomatic_complexity": _estimate_cc(node)}

[ ] FIX-05: Add coupling metric (import count) to file metrics
       File  : agents/cuqa_agent/src/report_generator.py
       Where : _python_metrics() function (around line 142)
       Bug   : No coupling metric is emitted. RDP uses it for
               has_multiple_dependencies and for severity scoring.
       Impact: has_multiple_dependencies always gets coupling=None → WARNING
               → FAILED. "Introduce Facade" is always rejected.
               Coupling-based severity bonuses never apply.
       Fix   : Count import statements as a proxy for coupling:
                   import_count = sum(
                       1 for n in ast.walk(tree)
                       if isinstance(n, (ast.Import, ast.ImportFrom))
                   )
               Add to metrics: "coupling": import_count

  PHASE 2 — MISSING SMELL DETECTORS — PYTHON (High Priority)

[ ] FIX-06: Add Switch Statements detector (Python)
       File  : agents/cuqa_agent/src/report_generator.py
       Where : _PythonSmellVisitor — add new visit method
       Bug   : No if/elif chain detection. RDP has "Replace Conditional with
               Polymorphism" mapped to "Switch Statements" but never gets triggered.
       Fix   : Count elif branches per function. If elif count >= 4, emit:
                   type: "SwitchStatements", severity: "medium"
               Also attach: cyclomatic_complexity of that function

[ ] FIX-07: Add Dead Code detector (Python)
       File  : agents/cuqa_agent/src/report_generator.py
       Where : _analyze_python_smells() or a new post-pass
       Bug   : No detection of unused functions/classes.
               RDP has "Remove Dead Code" but CUQA never triggers it.
       Fix   : After parsing, collect all function/class names and all
               Name references in the AST. Emit DeadCode smell for
               any function/class defined but never referenced in the file.

[ ] FIX-08: Add Comments smell detector (Python)
       File  : agents/cuqa_agent/src/report_generator.py
       Where : _python_metrics() or a post-analysis step
       Bug   : CUQA counts comment_lines but never uses it as a smell signal.
               A file with comment_lines/loc > 0.3 usually has complex code
               with poor naming — a candidate for Extract Method / Rename Method.
       Fix   : If comment_lines / lines_of_code > 0.3 and loc > 50, emit:
                   type: "Comments", severity: "low"

[ ] FIX-09: Add Duplicate Code detector (Python)
       File  : agents/cuqa_agent/src/report_generator.py
       Bug   : No duplication detection. RDP has Extract Method and Pull Up
               Method mapped to Duplicate Code but can never plan them.
       Fix   : Hash function bodies (normalised, whitespace stripped).
               If 2+ functions share the same hash, emit DuplicateCode smell.
               This unlocks "Extract Method" and "Pull Up Method" planning.

[ ] FIX-10: Add Message Chains detector (Python)
       File  : agents/cuqa_agent/src/report_generator.py
       Bug   : No chained call detection. RDP has "Hide Delegate" for
               Message Chains but never gets triggered.
       Fix   : Regex or AST walk for method call chains >= 3 deep
               (e.g. a.b().c().d()). Emit: type: "MessageChains"
               Also attach: chain_length metric (RDP checks metrics["chain_length"])

[ ] FIX-11: Add Lazy Class detector (Python)
       File  : agents/cuqa_agent/src/report_generator.py
       Bug   : No detection of near-empty classes.
               RDP has "Inline Class" and "Collapse Hierarchy" for Lazy Class.
       Fix   : If class has <= 2 methods and LOC < 30, emit:
                   type: "LazyClass", severity: "low"
